# Pasted text

Pasted text becomes a book with no source and one chapter, titled with its first line. It sits in the library with its own position and Continue, so playback, saving and sentence audio need no special case. It can be deleted like any book.

Rejected: a one-off reader that isn't saved, which would need its own position handling.

# Smaller Phase 3 choices

Proposed during Phase 3 planning on 2026-11-09:

- **Sleep timer options:** 15, 30, 45 and 60 minutes, and "end of chapter". It runs on the clock from when you set it, and it does nothing if it runs out while you're paused.
- **When time is up, playback pauses at the end of the sentence playing**, not mid-word. No fade-out.
- **"End of chapter" pauses before the next chapter.** The saved position is the next chapter's first sentence, so Continue starts it.
- **The timer isn't saved.** If the service is killed, playback has stopped anyway.
- **After the timer, resuming uses the existing rule:** one sentence back after 5 minutes away. Undo and tap to jump cover dozing off earlier.
- **The timer is set and shown in the app**, in the mini player. There is no lock-screen button for it.
- **Fixes also apply to spoken chapter titles**, since titles often contain names.
- **A chapter where every paragraph is skipped** plays nothing and moves on to the next one.
- **"Couldn't load the next chapter"** gets a second sentence: "You can switch source from the book screen."

# New chapters on a site

Update checks are out of the MVP. The book screen has pull-to-refresh, which fetches the chapter list again and adds only chapters not already listed. Existing chapters, their text and their sentence numbers are untouched. When auto-advance reaches the last known chapter, Lantern says "No more chapters yet", saves the position and stops.

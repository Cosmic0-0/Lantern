# Choosing a source when adding a book

[Chapter sources](chapter-sources.md) planned that Lantern picks the source listing the most chapters. That needs matching titles across sources ("Shadow Slave" against "Shadow Slave (Web Novel)") and fetching every candidate's chapter list on add.

Instead, search results group listings by normalized title, with sources in default-list order, and each row names its source. You tap the listing you want, and that becomes the book's source. Searching every source at once already removes the hunting. Automatic choice can come with Phase 3's switching a book to another source.
